# 물리 교과군 three.js 시뮬레이션 묶음

고등학교 「물리학」, 「역학과 에너지」, 「전자기와 양자」의 소단원별 인터랙티브 시뮬레이션 모음입니다. 현재 공통 틀과 시범 2종(전자기 유도, 운동량 보존)을 만들었습니다.

- 사이트: https://totemism1122.github.io/physicssimul/

- 기획안: `docs/plan_v0.4.md`
- 화면 시안: `docs/mockups/`
- 장면 디자인 견본: `docs/sample/scene_sample_4.html` (내려받아 브라우저로 열면 작동합니다)
