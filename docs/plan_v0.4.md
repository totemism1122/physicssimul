# 물리 교과군 three.js 시뮬레이션 묶음 기획안 v0.4

2026-11-18 (Claude Doc에서 내보낸 사본. 원본이 바뀌면 다시 내보내 교체합니다.)

## 1. 개요

물리 교과군 세 과목의 전 단원을 다루는 인터랙티브 시뮬레이션 52종을 하나의 공통 틀 위에 제작합니다. 교과서 내용을 기본으로 하고, 학생이 변인을 직접 바꾸며 탐구한 뒤 심화 내용까지 이어 갈 수 있게 합니다.

| 항목 | 확정 내용 |
| --- | --- |
| 범위 | 「물리학」, 「역학과 에너지」, 「전자기와 양자」 전 단원 |
| 제작 도구 | three.js |
| 필수 요소 | 인터랙티브 기능, 자유로운 변인 조작, 심화학습 |
| 2D 전환 | 직선 운동처럼 평면으로 충분한 내용은 해당 부분만 2D 화면으로 표시 |
| 심화 모드 | 교육과정 범위를 일부 넘는 내용 포함 |
| 사용 방식 | 실제 수업(교사 시연)과 학생 개별 탐구 겸용 |
| 분량 | 여러 개 묶음 |

접속 환경은 학생 개인 기기의 데이터 통신을 기준으로 합니다. 아이폰, 갤럭시, 크롬북, 아이패드에서 모두 작동해야 합니다.

기준 교과서는 최혁준 외 7인이 지은 「물리학」, 「역학과 에너지」, 「전자기와 양자」(각 2쇄)입니다. 교사용 지도서는 참고하지 않습니다(2026-11-18 결정).

## 2. 전체 구조

처음 접하는 사람도 바로 쓸 수 있도록 대상 중심 설계(OOUX)를 따릅니다. 사용자는 과목, 단원, 시뮬레이션, 메뉴, 조작 요소의 순서로 대상을 골라 들어갑니다. 모든 시뮬레이션은 같은 화면 틀을 씁니다.

### 2.1 진입 구조

화면은 세 단계로 이어지며, 단계 사이는 디졸브(0.2\~0.3초)로 전환합니다.

시뮬레이션에 들어가기 전의 화면(과목 선택, 단원 목록)은 2D로 만듭니다. 이 두 화면에서는 three.js를 불러오지 않으므로 첫 화면이 가볍게 열립니다.

| 단계 | 화면 | 구성 |
| --- | --- | --- |
| 1 | 과목 선택 | 화면 중앙에 과목 카드 3장 |
| 2 | 단원 목록 | 화면 중앙에 대단원 카드. 펼치면 중단원은 소제목으로 나오고 그 아래 소단원이 바로 보임. 펼칠 때는 소단원이 위에서부터 차례로 나타나고, 나머지 대단원 카드는 흐려짐 |
| 3 | 시뮬레이션 | 장면 준비가 끝난 뒤 디졸브로 등장 |

과목 카드는 인물 흉상으로 디자인합니다.

| 과목 | 인물 | 구도 |
| --- | --- | --- |

| 역학과 에너지 | 뉴턴, 아인슈타인 | 두 흉상이 같은 곳을 바라봄 |
| 전자기와 양자 | 맥스웰, 보어 | 두 흉상이 같은 곳을 바라봄 |

첫 화면의 확정 사항은 다음과 같습니다(2026-11-18).

- **화면 제목**: "Physics". 글꼴은 IM Fell English SC로 확정했습니다(Google Fonts, OFL 라이선스).
- **과목명 글꼴**: 시안에 쓴 명조 계열(Noto Serif KR)로 확정했습니다. 한글 글꼴은 용량이 크므로 화면에 쓰는 글자만 담아 내려받는 양을 줄입니다.
- **카드 문구**: 과목명만 표시합니다.
- **카드 배경**: 인물과 과목명이 놓인 칸은 투명하게 두고, 그 칸 전체를 클릭 영역으로 합니다. 마우스를 올리면 인물이 살짝 커지며, 터치 기기에서는 누르는 순간 같은 반응을 보입니다.
- **인물 배치**: 물리학은 갈릴레이를 뒤 가운데, 패러데이와 영을 앞 좌우에 둡니다. 나머지 두 카드는 뉴턴·맥스웰을 앞 왼쪽, 아인슈타인·보어를 뒤 오른쪽에 둡니다. 인물 크기는 시안대로 유지합니다.
- **화면 크기**: 1440×900뿐 아니라 24\~27인치 PC 화면(1920×1080, 2560×1440)에서도 비율을 유지하며 커지게 합니다.
- **전체 배경**: 우주 배경으로 확정했습니다.

화면 표현의 추가 확정 사항은 다음과 같습니다(2026-11-18).

- **배경**: 밝기와 채도를 조정한 남회색 우주 배경으로 확정했습니다.
- **강조 방식**: 글자 강조는 금색으로 합니다. 선택된 단추는 배경색보다 명도와 채도를 낮춰 표시합니다.
- **단원 목록**: 소단원 옆의 3D·2D 표시는 두지 않습니다.
- **왼쪽 메뉴**: 메뉴 이름은 두 글자로 씁니다. 메뉴를 펼치고 접는 단추를 두며, 펼치면 부채 모양으로 펼쳐집니다. 부채는 다섯 조각으로 나눈 부채살 조각 형태(시안 3A)로 확정했으며, 각 조각의 모서리는 둥글게 합니다.
- **장면(3D·2D) 디자인**: 현실적이고 세련된 방향으로 다시 정합니다. 세 방향의 견본을 비교한 뒤 정제된 삽화풍으로 확정했습니다. 장면의 배경은 실험실이며, 마블 무늬가 있는 실험대 위에 기구를 놓습니다. 화면을 돌려도 실험실이 보여야 합니다. 실험실은 밝고 따뜻한 색으로 하고 가구와 기구를 자세히 둡니다. 조명은 실제 건물처럼 천장에 격자 간격으로 놓인 조명판을 가정하고, 그림자도 그에 맞춥니다. 마블 무늬와 기구의 모양은 견본대로 확정했습니다. 배경과 조명도 견본대로 확정했습니다. 기준 견본은 장면\_디자인\_견본\_4.html입니다.

휴대전화는 가로와 세로를 모두 지원합니다. 가로 화면과 큰 화면에서는 패널이 옆으로 펼쳐지고, 세로 화면에서는 폭이 좁아 패널이 아래에서 위로 올라옵니다.

패널 고정을 허용해 변인과 그래프를 함께 볼 수 있게 합니다. 이 방식은 실제 사용 시험을 거쳐 수정할 수 있습니다.

원형 메뉴의 항목은 아래를 기본으로 하고, 세부 메뉴는 시뮬레이션마다 단원에 맞게 정합니다.

| 메뉴 | 공통 세부 메뉴 | 시뮬레이션마다 정하는 것 |
| --- | --- | --- |
| 변인 | 조작 변인, 변인 잠금 | 변인의 종류, 범위, 단위 |
| 그래프 | 그래프 선택, 이전 실행 겹쳐 보기 | 가로축과 세로축의 물리량 |
| 시간 제어 | 느리게, 한 단계씩, 처음으로 | 시간 변화가 없는 주제는 생략 |
| 표시 층 | 켜고 끄기 | 힘 화살표, 장(field) 선, 에너지 막대, 궤적 중 해당 항목 |
| 탐구 | 예측 질문, 도전 과제, 측정값 표 | 질문과 과제의 내용 |

**휴대전화 세로 화면 확정 사항 (2026-11-18)**

- 기준 크기: 가로 360, 세로 660(주소창이 보이는 작은 휴대전화를 어림한 값이며 실제 기기에서 확인합니다).
- 첫 화면: 가로 띠 카드. 인물은 왼쪽, 과목명은 오른쪽에 두고 세 과목을 한 화면에 모두 보입니다.
- 단원 목록: 대단원 카드를 세로로 쌓고, 화면을 넘는 부분은 위아래로 밀어서 봅니다.
- 시뮬레이션 화면: 조작 패널이 아래에서 올라오면 부채 메뉴는 자동으로 접힙니다. 이때 장면은 움직이지 않고 그대로 둡니다.
- 시점 단추(좌·우·정면·상단)는 고정 시점을 고를 때만 둘째 줄로 나타납니다.
- 세로 화면에서는 기구가 모두 들어오도록 카메라를 PC보다 약 1.3배 멀리 둡니다.
- 장면이 밝으므로 제목과 단추는 어두운 반투명 바탕 위에 올립니다(PC 화면에도 적용).
- 시안 파일: "물리 수업자료 제작/세로\_화면\_시안" 폴더.

### 2.3 두 가지 모드 축

- **기본과 심화**: 기본 모드는 교과서 수준의 변인만 보입니다. 심화 모드를 켜면 추가 변인과 정량 분석 도구가 열리고, 화면에 "교육과정 밖" 표지가 붙습니다.
- **수업용과 탐구용**: 수업용은 큰 글씨와 최소 조작부로 구성한 발표 화면입니다. 탐구용은 예측 질문과 도전 과제가 붙습니다.
- **전환 방법**: 두 모드 모두 화면 위쪽 모서리의 작은 단추로 바꿉니다. 주소 끝의 옵션으로도 지정할 수 있어, 수업용 링크와 탐구용 링크를 따로 나눠 줄 수 있습니다.

### 2.4 2D와 3D 규칙

| 유형 | 처리 | 예 |
| --- | --- | --- |
| 3D 전용 | 입체 구조나 시점 이동이 이해에 필요한 주제 | 자기장, 편광, 나선 운동 |
| 3D와 2D 전환 | 3D 장면을 고정 시점의 평면 그림으로 전환 | 포물선 운동, 궤도 운동 |
| 2D 전용 | 평면으로 충분한 주제 | 직선 충돌, 회로, 광선 추적, 에너지 준위 |

### 2.5 모든 시뮬레이션에 들어가는 탐구 장치

- **예측 후 관찰**: 실행 전에 결과를 고르게 하고, 실행 후 비교합니다.
- **변인 잠금**: 한 번에 하나만 바꾸는 모드와 모두 푸는 모드를 둡니다.
- **실행 기록 겹쳐 보기**: 이전 실행의 궤적과 그래프를 흐리게 남깁니다.
- **측정값 표**: 실행 결과를 표에 모아 비례 관계를 찾게 합니다.
- **도전 과제**: 목표 조건을 주고 변인을 탐색하게 합니다.

### 3.5 직접 조작 요소

모든 시뮬레이션은 슬라이더보다 장면 속 물체를 직접 끌어 조작하는 것을 우선합니다. 아래 표는 교과서 차례만 보고 적은 잠정안이며, 각 시뮬레이션을 만들 때 본문의 탐구 활동에 맞춰 확정합니다.

물체의 움직임은 학습 목표에 필요한 범위로 제한합니다. 제약 없이 자유롭게 두면 의도하지 않은 결과가 나와 혼란을 주기 때문입니다(견본 3에서 확인). 조작 방식은 다섯 가지로 통일합니다.

- **옮기기**: 물체를 끌어 위치를 바꿉니다.
- **놓기**: 물체를 끌어 올렸다가 손을 떼면 운동이 시작됩니다.
- **당기기**: 뒤로 당긴 만큼 처음 속력이 정해집니다.
- **돌리기**: 손잡이나 판을 돌립니다.
- **끼우기**: 부품을 끌어다 제자리에 연결합니다.

말씀하신 자유 낙하는 교과서 차례에 독립된 소단원이 없으므로, P-02(힘과 가속도)와 P-05(역학적 에너지 보존)에서 "물체를 끌어 올렸다 놓기"로 다룹니다.

### 3.7 시범 2종의 세부 메뉴 — 확정(2026-11-18)

교과서 본문(42\~49쪽, 120\~129쪽)을 읽고 정했습니다. 장면이 여럿인 시뮬레이션은 변인 메뉴의 첫 항목에서 장면을 고릅니다.

**P-13 전자기 유도.** 장면은 자석과 코일 하나입니다(기준 견본 4). 관을 따라 떨어지는 자석과 무선 충전 장면은 만들지 않습니다. 자석의 빠르기는 손으로 끄는 것이라 메뉴에 넣지 않고, 같은 빠르기로 비교할 때는 자동 시연 속력을 씁니다.

| 메뉴 | 기본 모드 | 심화 모드에서 추가 |
| --- | --- | --- |
| 변인 | 자석의 세기, 코일의 감은 수, 자동 시연 속력 | 코일의 단면적 |
| 그래프 | 유도 전류–시간 | 자기선속–시간(전류 그래프와 나란히) |
| 시간 | 재생·일시정지, 느리게, 처음으로 | 한 단계씩 넘기기 |
| 표시 | 자기장 선(모형), 유도 전류의 방향, 유도 전류가 만드는 자기장 | 자석이 받는 자기력, 자기선속 값 |
| 탐구 | 예상하고 확인하기(N극을 가까이·멀리), 세기 비교(빠르기·자석 세기·감은 수) | 자석이 코일을 등속으로 통과할 때, 눕힌 자석 |

**P-04 운동량 보존.** 장면은 충돌, 분리(용수철로 두 수레를 떼어 냄), 평면 충돌(심화 모드 전용) 셋입니다. 질량(추 끼우기), 처음 속도(당기기), 충돌 종류(범퍼 바꿔 끼우기)는 장면에서 직접 조작합니다. 속도와 운동량은 오른쪽을 (+)로 하여 부호와 함께 표시합니다. 평면 충돌 장면에서는 "한 레일 위" 제약을 풀고 수평면 안에서 움직이며, 구체적인 조작 방식은 제작할 때 정합니다.

| 메뉴 | 기본 모드 | 심화 모드에서 추가 |
| --- | --- | --- |
| 변인 | 장면 선택(충돌, 분리), 마찰(체크박스로 켜고 끔) | 장면 선택에 평면 충돌 추가, 튕기는 정도(0\~1 연속 조절) |

## 4. 기술 방침

외부 자원 없이 가볍게 열리는 정적 웹페이지로 만듭니다. 서버와 로그인이 없으므로 학생 개인정보를 다루지 않습니다.

| 항목 | 방침 |
| --- | --- |
| 3D | three.js. 기본 도형으로 구성하고 외부 3D 모델·큰 텍스처는 쓰지 않음 |
| 2D | 3D와 전환하는 주제는 three.js의 직교 카메라(orthographic camera)로 같은 장면을 평면화. 2D 전용 주제는 Canvas 2D |
| 그래프 | Canvas 2D로 직접 그림. 별도 차트 라이브러리 없음 |
| 파일 구성 | 공통 틀(화면 배치, 패널, 그래프, 시간 제어) 한 벌 + 시뮬레이션당 파일 하나 |
| 물리 계산 | 시뮬레이션마다 직접 작성. 범용 물리 엔진은 쓰지 않음(교과서 식과의 대응을 분명히 하기 위함) |
| 조작 | 터치와 마우스 동시 지원. 물체 끌기와 화면 회전이 충돌하지 않게 시점 고정 단추 제공 |
| 용량 목표 | 시뮬레이션 하나의 처음 내려받는 용량 1MB 이하(제안값) |
| 성능 목표 | 보급형 휴대전화, 크롬북, 아이패드에서 끊김 없이 작동. 입자 수와 그림자 효과는 기기에 따라 자동 축소 |
| 저장 | 학생 식별정보 없음. 실행 기록은 화면을 닫으면 사라짐(학생 기기 안에 저장할지는 추후 판단) |
| 제작 환경 | Claude Code로 제작, GitHub Desktop으로 저장소 관리. 커밋마다 작동하는 상태 유지 |

저장소에는 진행 기록 파일을 두어, 완료한 시뮬레이션과 다음 할 일을 단계마다 적습니다. 작업이 중단되어도 그 파일만 읽으면 이어서 진행할 수 있습니다.

- 문구 수정, 목록 정리 같은 단순 작업은 Haiku로 처리합니다.
- 최상위 모델은 공통 틀 설계와 계산이 까다로운 심화 주제(M-06 일반 상대론, P-17 오비탈, Q-13\~Q-17 양자)에만 씁니다.

## 6. 품질 기준

시뮬레이션마다 아래 네 가지를 통과해야 완료로 봅니다.

### 6.1 물리 정확성

- 보존량(에너지, 운동량)이 계산 오차 안에서 유지되는지 수치로 확인합니다.
- 답이 알려진 경우(등가속도 운동, 원 궤도, 단진동 주기)와 결과를 대조합니다.
- 근사를 쓴 경우 화면에 어떤 근사인지 밝힙니다.

### 6.2 오개념 방지

시각화 방식 자체가 오개념을 만들 수 있는 주제는 표현 방식을 따로 검토합니다.

| 주제 | 위험 | 대응 |
| --- | --- | --- |
| 전기장·자기장 선 | 선을 실재하는 줄로 인식 | 선의 개수를 바꾸는 조절 기능, 화살표 장 표현과 전환 |
| 원자 모형 | 전자를 궤도를 도는 공으로 인식 | 에너지 준위 그림을 기본으로 하고, 궤도 그림에는 모형임을 표시 |
| 시공간 휘어짐 | 고무막 비유를 실제 구조로 인식 | 고무막 대신 빛의 경로와 등가 원리 장면을 중심으로 구성 |
| 양자 중첩 | "동시에 두 곳에 있다"는 식의 이해 | 확률 분포와 측정 결과의 누적으로 표현 |
| 전류 | 전자가 빠르게 달려 전구를 켠다는 인식 | 전자의 느린 이동과 에너지 전달을 구분해 표시 |
| 열과 온도 | 열을 물질처럼 인식 | 입자 운동 에너지의 이동으로 표현 |

### 6.3 교육과정 범위

- 기본 모드는 2022 개정 교육과정 성취기준 안에서 구성합니다. 시뮬레이션마다 해당 성취기준을 제작 전에 원문으로 확인합니다.
- 심화 모드의 내용에는 "교육과정 밖" 표지를 붙여 시험 범위와 구분합니다.
- 학생용 문구는 해당 과목 학년 수준에 맞추고 최소한으로 둡니다.

### 6.4 기기와 접근

- 아이폰, 갤럭시, 크롬북, 아이패드에서 각각 열어 조작을 확인합니다.
- 휴대전화 세로 화면에서 모든 조작부가 손가락으로 누를 수 있는 크기인지 확인합니다.
- 색만으로 정보를 구분하지 않고 모양이나 글자를 함께 씁니다.

### 6.5 교과서 참고 절차

시뮬레이션 하나를 시작할 때마다 아래 순서로 자료를 읽고, 읽은 쪽수를 진행 기록 파일에 적습니다.

1. 교과서 해당 소단원 본문: 용어, 기호, 식의 표기, 삽화의 시점, 탐구 활용을 확인합니다. 기본 모드의 변인은 이것을 따릅니다.
2. 본문에 없는 내용만 심화 모드로 분류합니다.

지도서는 참고하지 않으므로, 오개념 검토는 교과서 본문과 6.2절의 표를 기준으로 합니다.
