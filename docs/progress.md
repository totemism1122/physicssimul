## 파일 구성

- `index.html` — 유일한 페이지. 주소 뒤 `#/…`로 화면을 구분합니다(`#/`, `#/physics`, `#/physics/P-13?mode=adv&use=class`).
- `css/base.css`(색·글꼴·우주 배경·디졸브), `css/home.css`(첫 화면·단원 목록). 길이는 "설계 픽셀 × `--u`"로 적어 화면 크기에 비례합니다(가로 화면은 1920×1080, 세로 화면은 360×660 기준).
- `js/main.js`(주소 처리, 디졸브), `js/data/units.js`(52종 목록, `ready: true`가 제작된 것), `js/home/`(첫 화면, 단원 목록, 별 배경).
- `assets/img/` — 화면용 흉상(WebP, 폭 360·760). 원본은 `assets/busts/`.
- `assets/fonts/*-sub.woff2` — 쓰는 글자만 추린 글꼴.
- `tools/` — 제작용 도구. `node tools/serve.mjs`(미리보기, http://localhost:8013), `node tools/subset-fonts.mjs`(글꼴 추리기), `node tools/make-images.mjs`(흉상 줄이기).

## 작업할 때 주의

- **화면에 보이는 글자를 바꾸거나 더하면 `node tools/subset-fonts.mjs`를 다시 돌립니다.** 돌리지 않으면 새 글자만 다른 글꼴로 보입니다. Noto Serif KR 원본은 저장소에 넣지 않았습니다(`tools/src-fonts/`, 내려받는 곳은 스크립트 머리말).
- 이 Mac에서는 `git`, `python3` 명령을 쓰지 않습니다(개발자 도구 설치 창이 뜸). 커밋은 사용자가 GitHub Desktop으로 합니다.
- 시뮬레이션 주소는 지금 임시 화면(제목만)으로 이어집니다. `js/main.js`의 `placeholderScreen`을 2단계에서 화면 틀로 바꿉니다.
- 첫 화면의 흉상 배치 수치는 `js/home/first.js`의 `BUSTS`에 있습니다(시안 `pc_1_first.png`와 맞춘 값).

## 확정된 결정 (2026-11-18, 기획안에 없는 것)

공통
- 2D 전용 시뮬레이션에도 시점 줄을 두되, 의미 있는 시점만 누를 수 있고 나머지는 흐리게 둡니다(P-04는 정면·상단).
- 재생·일시정지는 **자동 시연에만** 해당합니다(모든 시뮬레이션 공통). 그래프는 재생·일시정지와 상관없이 물체가 움직이는 대로 그려집니다.
- 탐구 장치는 3.7절 표에 있는 것만 만들고, 나머지(겹쳐 보기, 도전 과제 등)는 필요한 시뮬레이션이 나올 때 틀에 더합니다.
- 옛 시안과 3.7절이 다르면 3.7절을 따릅니다. P-04의 "충돌 시간 조작"(3.1절)은 넣지 않습니다.
- 고정 시점에서 자석 끌기: 좌·우에서는 위아래로만, 상단에서는 좌우로만 끌립니다.
- P-04 평면 충돌(심화)은 위에서 본 Canvas 2D 그림으로 만듭니다.
- 아직 없는 시뮬레이션은 단원 목록에서 흐리게 보이고 눌리지 않습니다.
- 부채 메뉴는 항상 다섯 조각(회전 없음). 기본 상태는 기본·탐구 모드, 3D는 자유 시점.
- "교육과정 밖" 표지는 심화 단추 옆과 심화 전용 항목에 작은 금색 글자로 붙입니다.
- 수업 모드는 글자와 단추를 키우고 탐구 조각을 흐리게 둡니다.
- 용량 1MB는 실제 전송량(압축 후)으로 잽니다.
- 휴대전화 가로와 태블릿은 PC 배치를 줄여 맞춥니다. 세로 화면의 패널 고정 방식은 2단계에서 보고 정합니다.

P-13 전자기 유도
- 자석의 세기: 1~25, 1단위. 단위는 보이지 않고 결과를 정성적으로 보여 줍니다.
- 코일의 감은 수: 50~300, 10단위.
- 그래프 축에 숫자를 넣지 않습니다.
- "예상하고 확인하기" 질문은 일단 넣지 않습니다.

P-04 운동량 보존
- 수레의 질량은 1 kg 고정. 추는 100 g~1 kg, 100 g 단위.
- 속력은 1~20 m/s, 1 m/s 단위.
- 기록 표는 운동량 보존 실험의 기본 기록 틀을 따릅니다.
- 예제 상황의 내용과 분리 장면을 시작하는 조작은 5단계 전에 제안해서 확인받습니다.
