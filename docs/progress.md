## 파일 구성

- `index.html` — 유일한 페이지. 주소 뒤 `#/…`로 화면을 구분합니다(`#/`, `#/physics`, `#/physics/P-13?mode=adv&use=class`).
- `css/base.css`(색·글꼴·우주 배경·디졸브), `css/home.css`(첫 화면·단원 목록). 길이는 "설계 픽셀 × `--u`"로 적어 화면 크기에 비례합니다(가로 화면은 1920×1080, 세로 화면은 360×660 기준).
- `js/main.js`(주소 처리, 디졸브), `js/data/units.js`(52종 목록, `ready: true`가 제작된 것), `js/home/`(첫 화면, 단원 목록, 별 배경).
- `css/sim.css` — 시뮬레이션 화면 틀. 길이는 시안(1920×1080)의 픽셀 × `--s`. 휴대전화는 같은 그림을 줄여 쓰고 글자·단추에만 최소 크기를 둡니다. 시뮬레이션을 열 때만 내려받습니다.
- `js/frame/` — 화면 틀. `frame.js`(조립, 상태, 모드, 시점, 패널 배치), `fan.js`(부채 메뉴), `panel.js`(조작 패널: 슬라이더·선택·그래프·글, 잠금·고정), `graph.js`(그래프 축), `clock.js`(재생·일시정지의 시계).
- `js/frame/view3d.js`(3D 화면: 카메라, 자유·고정 시점, 끌기 전달, 기기별 품질 축소), `lab.js`(실험실·조명·실험대, 견본 4), `kit.js`(무광 재질, 도형, 캔버스 무늬, 정적 물체 합치기).
- `js/vendor/three.module.min.js` — three.js r160(견본 4와 같은 판, MIT). 3D 시뮬레이션을 열 때만 내려받습니다(압축 후 약 167KB).
- `js/sims/P-13.js`, `js/sims/P-04.js` — 시뮬레이션마다 파일 하나. P-13은 메뉴, 칠판 글씨(`board`), 장면(`create`)이 들어 있고, P-04는 아직 메뉴 정의만 있습니다.
- `assets/img/` — 화면용 흉상(WebP, 폭 360·760). 원본은 `assets/busts/`.
- `assets/fonts/*-sub.woff2` — 쓰는 글자만 추린 글꼴.
- `tools/` — 제작용 도구. `node tools/serve.mjs`(미리보기, http://localhost:8013), `node tools/subset-fonts.mjs`(글꼴 추리기), `node tools/make-images.mjs`(흉상 줄이기).

## 작업할 때 주의

- **화면에 보이는 글자를 바꾸거나 더하면 `node tools/subset-fonts.mjs`를 다시 돌립니다.** 돌리지 않으면 새 글자만 다른 글꼴로 보입니다. Noto Serif KR 원본은 저장소에 넣지 않았습니다(`tools/src-fonts/`, 내려받는 곳은 스크립트 머리말).
- 이 Mac에서는 `git`, `python3` 명령을 쓰지 않습니다(개발자 도구 설치 창이 뜸). 커밋은 사용자가 GitHub Desktop으로 합니다.
- 2D 시뮬레이션(P-04)의 장면은 아직 임시 그림입니다(`js/frame/frame.js`의 `drawScene`). 5단계에서 바꿉니다.
- 3D 시뮬레이션은 `create({ T, kit, view, world, ctx })`에서 기구를 `world`(실험대 위)에 놓고 `{ update(dt) }`를 돌려줍니다. `update`는 그림을 다시 그려야 할 때 true를 돌려줍니다(바뀐 것이 없으면 그리지 않아 전지를 아낍니다). 끌기는 `view.setTool({ pick, cursor, start, move, end })`로 받습니다.
- CSS 이름 주의: 시뮬레이션 화면의 뿌리는 `.sim`입니다. `css/sim.css`는 한 번 내려받으면 다른 화면에도 계속 적용되므로, 첫 화면·단원 목록에서 같은 이름을 쓰면 안 됩니다(단원 목록의 소단원 줄은 `.entry`).
- 시뮬레이션 파일의 규격: `view`(3d·2d), `fixedViews`(누를 수 있는 고정 시점), `menus`(변인 `vars`, 그래프 `graph`, 시간 `time`, 표시 `layers`, 탐구 `inquiry`). 항목의 `kind`가 `slider`·`choice`·`graph`·`note`이면 패널이 열리고, `toggle`·`action`이면 누르는 즉시 작동합니다. `advanced: true`는 심화 모드에서만 보입니다.
- 틀과 장면은 `ctx`로 이어집니다: `ctx.values`(값), `ctx.locked`(잠근 변인), `ctx.view`(시점), `ctx.on('change'|'action'|'play'|'tick'|'view'|'mode', …)`.
- 미리보기 창이 가려져 있으면 애니메이션이 돌지 않습니다. 화면을 수치로 점검할 때는 `document.getAnimations().forEach(a => a.finish())`를 먼저 부릅니다.
- 첫 화면의 흉상 배치 수치는 `js/home/first.js`의 `BUSTS`에 있습니다(시안 `pc_1_first.png`와 맞춘 값).

## 확정된 결정 (2026-11-18, 기획안에 없는 것)

공통
- 2D 전용 시뮬레이션에도 시점 줄을 두되, 의미 있는 시점만 누를 수 있고 나머지는 흐리게 둡니다(P-04는 정면·상단).
- 재생·일시정지는 **자동 시연에만** 해당합니다(모든 시뮬레이션 공통). 그래프는 재생·일시정지와 상관없이 물체가 움직이는 대로 그려집니다.
- 탐구 장치는 3.7절 표에 있는 것만 만들고, 나머지(겹쳐 보기, 도전 과제 등)는 필요한 시뮬레이션이 나올 때 틀에 더합니다.
- 옛 시안과 3.7절이 다르면 3.7절을 따릅니다. P-04의 "충돌 시간 조작"(3.1절)은 넣지 않습니다.
- 고정 시점에서 자석 끌기: 좌·우에서는 위아래로만, 상단에서는 좌우로만 끌립니다.
- P-04 평면 충돌(심화)은 위에서 본 Canvas 2D 그림으로 만듭니다.
- 아직 없는 시뮬레이션은 단원 목록에서 흐리게 보이고 눌리지 않습니다.
- 부채 메뉴는 항상 다섯 조각(회전 없음). 기본 상태는 기본·탐구 모드, 3D는 자유 시점.
- "교육과정 밖" 표지는 심화 단추 옆과 심화 전용 항목에 작은 금색 글자로 붙입니다.
- 수업 모드는 글자와 단추를 키우고 탐구 조각을 흐리게 둡니다.
- 용량 1MB는 실제 전송량(압축 후)으로 잽니다.
- 휴대전화 가로와 태블릿은 PC 배치를 줄여 맞춥니다. 세로 화면의 패널 고정 방식은 2단계에서 보고 정합니다.

P-13 전자기 유도
- 자석의 세기: 1~25, 1단위. 단위는 보이지 않고 결과를 정성적으로 보여 줍니다.
- 코일의 감은 수: 50~300, 10단위.
- 그래프 축에 숫자를 넣지 않습니다.
- "예상하고 확인하기" 질문은 일단 넣지 않습니다.

P-04 운동량 보존
- 수레의 질량은 1 kg 고정. 추는 100 g~1 kg, 100 g 단위.
- 속력은 1~20 m/s, 1 m/s 단위.
- 기록 표는 운동량 보존 실험의 기본 기록 틀을 따릅니다.
- 예제 상황의 내용과 분리 장면을 시작하는 조작은 5단계 전에 제안해서 확인받습니다.

## 3D↔2D 전환을 하지 않기로 한 결정 (2026-11-18, 사용자)

- 기획안에서 "3D↔2D"로 적힌 시뮬레이션(P-05, P-18, M-02, M-04, M-09, M-10, Q-07)은 2D로 전환하지 않고 3D 그대로 만듭니다. 직교 카메라로 평면화하는 방식(기획안 2.4절, 4절)은 쓰지 않습니다.
- 대신 시뮬레이션마다 고정 시점을 그 특성에 맞게 제한합니다. 시뮬레이션 파일의 `fixedViews`에 누를 수 있는 시점만 적고(나머지는 흐리게), 처음 고정 시점은 정면이 있으면 정면, 없으면 목록의 첫째입니다. 어떤 시점을 둘지는 각 시뮬레이션을 만들 때 정합니다.
- 2D 전용(Canvas 2D)으로 정한 시뮬레이션은 그대로입니다.
- 기획안 파일은 Claude Doc에서 내보낸 사본이라 고치지 않았습니다. 원본을 고친 뒤 다시 내보내 교체해야 합니다(2.4절, 3절 표의 "화면" 열, 4절의 2D 행).

## 3단계에서 정한 것 (사용자 확인 대기)

- 고정 시점의 카메라: 정면·좌·우는 실험대 높이에서 조금 내려다보고, 상단은 바로 위에서 봅니다. 시점을 바꾸면 카메라가 미끄러지듯 옮겨 가고, 자유 시점으로 돌아오면 전에 보던 각도로 돌아갑니다.
- P-13의 자석: 좌·우에서는 위아래로만, 상단에서는 좌우로만 끌립니다(이때는 돌릴 수 없음). 자유 시점에서도 운동 평면이 거의 선으로 보이는 각도에서는 같은 방식이 됩니다.
- 재생 단추는 자동 시연(자석이 코일을 드나듦)이고, 자석을 손으로 잡으면 자동 시연이 멈춥니다. "처음으로"는 자석을 처음 자리에 세워 놓습니다.
- 기기별 품질: 화면이 계속 느리면(초당 약 30장 미만) 그림자 조명 수와 해상도를 한 단계씩 낮춥니다. 성능이 낮은 터치 기기는 처음부터 한 단계 낮게 시작합니다.
- 실험실 방은 재질별로 합쳐 그립니다(그리기 호출 약 500회 → 51회).

## 2단계에서 정한 것 (사용자 확인)

- 표시 메뉴의 항목과 시간 메뉴의 "느리게"는 패널 없이 세부 메뉴 단추를 눌러 바로 켜고 끕니다(켜지면 네모가 채워짐). "처음으로", "한 단계씩"도 누르면 바로 작동합니다.
- 고정한 패널은 넓은 화면에서는 오른쪽에 쌓이고, 세로 화면에서는 재생 단추 아래에 하나만 놓입니다. 세로 화면에서 부채 메뉴를 펼치면 고정 패널은 잠시 사라졌다가 접으면 돌아옵니다.
- "교육과정 밖" 표지는 금색 마름모이며, 심화 단추 아래와 심화 전용 항목 옆에 붙습니다.
- 세부 메뉴 단추에 맞게 줄인 이름: "유도 전류의 자기장"(유도 전류가 만드는 자기장), "주고받는 힘"(충돌 중 두 수레가 주고받는 힘), "충돌 순간으로", "예제 상황", "운동 에너지 비교", "등속으로 통과".
- 임시로 넣은 범위: 자동 시연 속력 0.2~1.0 m/s(0.1 단위), 코일의 단면적 1~3배(0.5 단위). 4단계 전에 확인받습니다.
- 탐구 패널의 글은 자리만 잡아 둔 임시 문구입니다(4·5단계에서 내용을 채움).
